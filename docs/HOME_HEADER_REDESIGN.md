# 首页 Header · 中国卡通插画风重构说明

## 第一阶段：示例 Header 视觉拆解

### 1️⃣ 背景色

- **高饱和红橙渐变**：从深红/朱红过渡到橙/金橙，不是淡粉或浅橙，饱和度明显偏高。
- **有纹理或图案**：背景上可见浅色纹样（云纹、圆点、抽象图案），半透明叠加，避免「纯渐变」的扁平感。
- **不是纯渐变**：即有「底色 + 纹理层」的层次，节日感更强。

### 2️⃣ 插画元素

- **卡通人物**：右侧出现旅行/春节主题的卡通角色（如背包、帽子、骑马或站立），圆润线条、偏亲子风。
- **地图元素**：简化地图轮廓或路线、地点标记，增强「旅行/出发」的故事感。
- **小装饰**：烟花、灯笼、定位点、温泉等小图标，分散在画面中，增加活泼感。
- **插画位于右侧**：左侧留出空间给标题，右侧插画可略溢出边界，更自然。

### 3️⃣ 标题

- **中文大字**：主标题是视觉焦点，字号明显大于副标题和搜索栏。
- **手写感/节日感**：字体偏圆润或带笔触，非标准黑体，可有轻微描边或阴影。
- **多行排列**：如「爱你老己的」+「新春首站之旅」两行，或三行，避免单行过长。
- **高对比**：白色或浅黄色字，配合深色/渐变阴影或描边，在任何背景下都可读。
- **字间距略紧**：标题区紧凑，不松散。

### 4️⃣ 情绪

- **喜庆**：红橙主色、节日文案、烟花等元素。
- **活泼**：卡通造型、圆角、小装饰。
- **有故事感**：像「新春首站」「一起出发」等文案，配合插画形成叙事。
- **亲子/旅行**：人物与地图、背包等符号强化场景。

## 新 Header 结构说明

1. **Layer 1 — 红橙渐变背景**  
   - 使用高饱和红→橙渐变（可延用 `homeHeaderRed` / `homeHeaderOrange`）。  
   - 叠加一层**轻微图案纹理**（如半透明圆点或简单纹样），避免纯平。

2. **Layer 2 — 插画主视觉**  
   - 右侧 `Positioned` 放置卡通插画图（网络图或本地 asset）。  
   - 插画尺寸略大，可向右/向下溢出边界（如 `right: -24, bottom: -16`），更自然。  
   - 仅使用插画风图片，不用摄影图。

3. **Layer 3 — 标题区**  
   - 左侧底部：**大号中文标题**，两行：「爱你老己的」「新春首站之旅」。  
   - 加粗、白色或浅黄、字间距略紧、多阴影保证可读。  
   - 可加小装饰（如小烟花 icon、定位点）增强节日感。

4. **Layer 4 — 搜索框**  
   - 顶置（SafeArea 下）：白色胶囊、圆角 30+、定位 icon、轻阴影，浮在最上层。

5. **标题可读性**  
   - 标题区底部可加一道透明→半透明黑的渐变遮罩，保证白字在任何情况下都清晰。

## 颜色定义（沿用 + 补充）

- **渐变**：`AppColors.homeHeaderRed` → `AppColors.homeHeaderOrange`，底部可过渡到 `warmBackground` 或半透明深色。  
- **标题**：`Colors.white` 或 `Color(0xFFFFF8E1)`（浅黄），阴影用 `Colors.black.withValues(alpha: 0.5)` 等。  
- **纹理**：半透明白或浅色，alpha 约 0.06–0.1。  
- **不用灰色**：装饰与主文案均不用中性灰，保持高饱和、节日感。

---

## 插画处理方式

- **来源**：继续使用 `kHomeHeaderCartoonUrl`（可替换为本地 asset 如 `assets/images/header_cartoon.png`）。  
- **布局**：`Positioned(right: -24, bottom: -20)` 或类似，`Alignment.bottomRight`，宽高约 70%–85% 的 Header 高度，允许溢出。  
- **加载失败**：`errorWidget` 显示纯色红底 + 图标，不出现灰块。  
- **非摄影**：仅用插画/手绘风图，不用真实摄影作主视觉。
