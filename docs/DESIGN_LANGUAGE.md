# 享梦游 · 设计语言系统

基于中国旅行类商业 App 视觉逆向分析，抽象出的**统一、高级、可复用、可规模扩展**的设计语言。本系统高于参考截图水准，适用于全产品线。

---

## 1️⃣ 颜色系统

### 主色（Primary）
| 角色 | 色值 | 用途 |
|------|------|------|
| **Primary** | `#2E9B54` | 主按钮、选中态、链接、核心图标 |
| **Primary Light** | `#3DBE6C` | 悬浮、浅底、次要强调（与现有品牌绿衔接） |
| **Primary Dark** | `#24804A` | 按下态、深色背景上的主色 |
| **Primary Pale** | `#E8F5EC` | 标签背景、高亮区块、弱强调 |

### 辅助色（Secondary / Accent）
| 角色 | 色值 | 用途 |
|------|------|------|
| **Accent Warm** | `#FF6B35` | 促销、热门、TOP 标签、节日 |
| **Accent Cool** | `#1890FF` | 信息、链接、部分分类图标 |
| **Accent Gold** | `#FAAD14` | 评分、星级、签到、权益 |

### 功能色（Semantic）
| 角色 | 色值 | 用途 |
|------|------|------|
| **Price / Action** | `#F2483D` | 价格、下单、强 CTA（与主绿二选一或组合） |
| **Success** | `#52C41A` | 成功、已确认、保障勾选 |
| **Warning** | `#FAAD14` | 待付款、即将过期 |
| **Error** | `#F5222D` | 失败、错误、不可用 |
| **Info** | `#1890FF` | 提示、说明 |

### 灰阶系统（Neutral）— 商业级对比度
| 角色 | 色值 | 用途 |
|------|------|------|
| **Text Primary** | `#1A1A1A` | 主标题、正文主色（白底 >12:1） |
| **Text Secondary** | `#525252` | 副标题、次要信息（约 8:1） |
| **Text Tertiary** | `#737373` | 辅助说明、占位符（约 4.6:1） |
| **Text Disabled** | `#BFBFBF` | 禁用、不可点击 |
| **Border** | `#E5E5E5` | 边框、分割线 |
| **Divider** | `#EEEEEE` | 内部分割 |
| **Surface** | `#F5F7FA` | 页面基底、次级背景 |
| **Background** | `#FAFBFC` | 全局背景 |
| **Card / Paper** | `#FFFFFF` | 卡片、弹窗、输入区 |

### 渐变规范
- **品牌渐变**：`Primary Dark → Primary`，用于头部、主 CTA 按钮。
- **页面背景渐变**：`#F0F9F4 → #E8F5EC → #F8F9FA`（三阶），用于全屏背景，保持与主色协调。
- **按钮渐变**：同品牌渐变，可选 90deg 或 180deg，增强立体感。

## 2️⃣ 字体系统

### 标题层级（H1–H6）
| 层级 | 字号 | 字重 | 行高 | 字间距 | 用途 |
|------|------|------|------|--------|------|
| **H1 / Display** | 28px | Bold (700) | 1.25 | 0 | 营销主标题、落地页首屏 |
| **H2** | 22px | Bold (700) | 1.3 | 0.1 | 页面主标题、模块标题 |
| **H3** | 18px | Semi-bold (600) | 1.35 | 0.1 | 区块标题、卡片主标题 |
| **H4** | 16px | Semi-bold (600) | 1.4 | 0.1 | 列表项标题、弹窗标题 |
| **H5** | 15px | Medium (500) | 1.4 | 0 | 小节标题 |
| **H6** | 14px | Medium (500) | 1.45 | 0 | 标签式标题、Tab |

### 正文
| 角色 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| **Body Large** | 16px | Regular (400) | 1.5 | 长文、详情描述 |
| **Body Medium** | 14px | Regular (400) | 1.5 | 默认正文、列表描述 |
| **Body Small** | 12px | Regular (400) | 1.45 | 辅助说明、备注 |

### 标签与辅助
| 角色 | 字号 | 字重 | 用途 |
|------|------|------|------|
| **Caption** | 12px | Regular | 图注、时间、来源 |
| **Overline** | 11px | Medium | 分类标签、角标 |
| **Label** | 12–14px | Medium | 表单项标签、按钮内文 |

### 价格
| 角色 | 字号 | 字重 | 颜色 | 用途 |
|------|------|------|------|------|
| **Price Large** | 20px | Bold | Price/主色 | 主价格、详情页价格 |
| **Price Medium** | 16px | Semi-bold | Price/主色 | 列表卡片价格 |
| **Price Small** | 14px | Medium | Price/主色 | 副价格、起价后缀 |
| **Price Unit** | 比主价格小 2–4px | Regular | 同色或 Tertiary | “起”“/晚”“/人” |

### 原则
- 同一模块内标题层级不超过 2 级落差（如不同时用 H1 与 H5）。
- 价格与主 CTA 文案必须与正文有明确字重/颜色区分。
- 全产品使用同一套字号阶梯，禁止随意插值（如 13px、15px 仅在有明确角色时使用）。

## 3️⃣ 间距系统

### 基础单位：4px
所有间距为 4 的整数倍，保证对齐与节奏统一。

### 标准阶梯
| Token | 数值 | 用途 |
|-------|------|------|
| **xs** | 4px | 图标与文字间距、紧凑标签内边距 |
| **sm** | 8px | 行内元素间距、列表项内小间隙 |
| **md** | 12px | 卡片内区块间距、表单项间距 |
| **lg** | 16px | 页面左右边距、卡片内边距、列表项间距 |
| **xl** | 20px | 模块间间距、弹窗内区块间距 |
| **xxl** | 24px | 区块间大间距、上下屏边距 |

### 页面级
- **水平边距**：内容区左右统一 **16px**（lg），特殊全屏图可破格。
- **垂直边距**：顶部安全区下方 **16–20px**；底部安全区上方 **24px**。
- **列表项间距**：**12px**（md）或 **16px**（lg），整 App 统一选一档。

### 组件内
- 按钮：水平 **20–24px**，垂直 **10–12px**（大按钮可 14px）。
- 卡片：内边距 **16px**（lg）。
- 弹窗：内边距 **20px**（xl），标题与内容间距 **16px**。

---

## 4️⃣ 圆角系统

### 规范
- 全产品圆角仅使用以下三档，禁止任意值（如 6、10、14）。

### 小圆角（Small）
- **值**：**4px**
- **用途**：标签、Chip、输入框、小按钮、表格单元格

### 中圆角（Medium）
- **值**：**8px**
- **用途**：卡片、列表项、图片缩略图、次级按钮、日期块

### 大圆角（Large）
- **值**：**12px**
- **用途**：主 CTA 按钮、弹窗容器、顶部 Sheet、搜索栏外框

### 全圆角（Pill / Full）
- **值**：**9999px** 或 **height/2**
- **用途**：胶囊按钮、Tab 选中背景、头像、图标按钮

### 组件映射表
| 组件 | 圆角 |
|------|------|
| 主按钮 | Large (12px) |
| 次级/文字按钮 | Small (4px) 或无 |
| 输入框 | Small (4px) |
| 搜索栏 | Pill 或 Large |
| 卡片 | Medium (8px) |
| 列表项 | Medium (8px) |
| 弹窗/Sheet | Large (12px)，仅顶角或全角 |
| 标签 Tag | Small (4px) |
| 头像/图标按钮 | Full |

## 5️⃣ 阴影系统

### 原则
- 仅用三层：轻 / 中 / 重；颜色统一为带透明度的黑，不采用彩色阴影。
- 阴影用于表达层级（卡片 > 背景，弹窗 > 卡片），不用于装饰。

### 轻（Light）
- **用途**：默认卡片、列表项、输入框聚焦
- **参数**：单层，Y 2–4px，模糊 8–12px，透明度 4–6%
- **示例**：`0 2px 8px rgba(0,0,0,0.06)`

### 中（Medium）
- **用途**：悬浮卡片、下拉菜单、主按钮、选中卡片
- **参数**：单层或双层，Y 4–6px，模糊 12–16px，透明度 6–10%
- **示例**：`0 4px 12px rgba(0,0,0,0.08)` 或叠加一层 `0 2px 4px rgba(0,0,0,0.04)`

### 重（Heavy）
- **用途**：弹窗、Bottom Sheet、固定底栏
- **参数**：双层或三层，Y 8–16px，模糊 24–32px，透明度 8–12%
- **示例**：`0 8px 24px rgba(0,0,0,0.12)` + `0 2px 8px rgba(0,0,0,0.06)`

### 层级规则
- 背景无阴影；卡片用 Light；悬浮/按下用 Medium；弹窗/Sheet 用 Heavy。
- 同一层级内（如列表内所有卡片）只使用一种阴影强度。

## 6️⃣ 卡片设计规范

### 结构
- **容器**：白底（Card/Paper），中圆角（8px），轻阴影（Light）。
- **内边距**：统一 **16px**。
- **可点击卡片**：带按压态（缩放或阴影变化），与列表项一致。

### 内容层级
- **主标题**：H3 或 H4，主色字，一行截断。
- **副标题/描述**：Body Small 或 Caption，Tertiary 色，最多 2 行截断。
- **标签区**：横向排列，Overline 或 Caption，与主文间距 8px。
- **价格**：右下或独立行，Price Medium/Large，与主色/价格色一致。

### 图片区（若有）
- 比例：**16:9** 或 **4:3**，统一选一；左侧小图可用 **1:1**。
- 圆角：与卡片一致（8px），或仅顶左/顶右 8px。
- 叠加信息：仅出发地/标签，半透明底 + 白字，圆角 4px。

### 禁止
- 卡片内不再嵌套带独立阴影的“子卡片”，用分割线或留白区分即可。
- 同一列表内卡片样式、内边距、圆角必须完全一致。

---

## 7️⃣ 列表设计规范

### 整体
- **背景**：页面使用 Surface 或渐变背景，列表区不强制白底。
- **左右边距**：与页面一致，**16px**。
- **项间距**：**12px** 或 **16px**，全 App 统一。

### 列表项
- **高度**：最小 56px（单行），双行 72–80px，带图卡片按内容自适应。
- **分割**：可选 1px Divider 或纯间距，二选一；若用分割线，与左右边距对齐或内缩 16px。
- **点击态**：整项可点击，有 Press 态（透明度或背景色变化）；若使用卡片样式，则遵循卡片规范。

### 内容结构
- **左图**（可选）：固定宽高或比例（如 72×72 或 16:9），圆角 8px。
- **主文**：标题 H4/ Body Medium，副标题 Body Small，Tertiary。
- **右侧**：价格、箭头、角标、时间等，右对齐；箭头统一用系统 Chevron。

### 空态 / 加载
- 空态：插画或图标 + 一句文案 + 可选主按钮，垂直居中。
- 加载：骨架与列表项结构一致（图+文+文），使用统一骨架色与动画。

---

## 8️⃣ 底部导航设计规范

### 布局
- **高度**：56px + 安全区，内容垂直居中。
- **项数**：3–5 个，等分；图标在上，文字在下，间距 4px。
- **背景**：Card/Paper（#FFFFFF），与内容区用轻阴影或顶部分割线区分。

### 图标与文案
- **图标**：24×24dp 或 28×28dp，统一线框/填充风格；选中为填充或主色。
- **文案**：Caption 或 Label，12–14px；选中 Primary，未选 Tertiary。
- **角标**：红点或数字，位于图标右上，不遮挡文字。

### 选中态
- 选中：主色（Primary）图标 + 主色文字；可选浅底（Primary Pale）或不加底。
- 未选：Tertiary 图标 + Tertiary 文字。
- 禁止使用下划线或粗边框，保持简洁。

### 与内容区关系
- 固定于底部，滚动时内容从底部栏下缘滑过；底部栏始终在同一层级（阴影一致用 Light 或 Medium 一种）。

---

## 9️⃣ 弹窗设计规范

### 类型
- **Dialog**：居中小窗，用于确认、简单表单。
- **Bottom Sheet**：自底上滑，用于选项、日期、多行内容。
- **Full-screen Overlay**：全屏遮罩 + 内容区（如日历），顶部大圆角。

### 通用
- **遮罩**：黑色 40–50% 透明度，点击关闭。
- **背景**：Card/Paper，白底。
- **圆角**：Dialog 四角 Large（12px）；Sheet / 全屏 overlay 仅顶部两角 Large（12–16px）。

### Dialog
- **最大宽度**：90% 屏宽或 320px，取较小者。
- **内边距**：20px；标题与内容 16px；按钮区与内容 16px，按钮之间 12px。
- **标题**：H4，居中或左对齐，与关闭按钮同排时留足间距。
- **按钮**：主按钮 + 次按钮（文字按钮），主按钮右或下。

### Bottom Sheet
- **高度**：由内容决定，支持拖拽；最大约 90% 屏高。
- **内边距**：20px 水平，顶部 16px，底部加安全区。
- **拖拽条**：顶部居中 32×4 圆条，Tertiary 色。
- **阴影**：Heavy，使 Sheet 明显浮于内容之上。

### 全屏类（如日历）
- **顶部圆角**：12–16px。
- **标题栏**：与内容区间 16px；关闭/确定分列左右或右右。
- **内容区**：内边距 20px，可滚动。
- **底部主按钮**：固定底，全宽，留安全区，圆角 Large，Heavy 阴影或与 Sheet 一致。

### 禁止
- 弹窗内再弹窗（优先合并或改为同一弹窗内 Tab/步骤）。
- 弹窗内使用与页面不一致的字体或主色。

## 附录 A：设计原则（设计系统级）

1. **一致性**：同一组件在全 App 内仅一种视觉规格（颜色、圆角、阴影、间距）。
2. **层级清晰**：通过字号、字重、颜色、阴影明确区分背景、内容、浮层。
3. **可访问性**：主文对比度 ≥4.5:1，可点击区域 ≥44×44pt。
4. **可扩展**：新增页面只从本语言中选 Token，不新增临时色、临时字号。
5. **商业化**：价格、主 CTA、信任标签（成团/确认/退改）显眼且规范统一。

## 附录 B：商业化精修（中国 App Store 前列旅行 App 目标）

### 信息密度
- 页面内边距：水平 16px，垂直 16px（`paddingPage`），避免过疏。
- 列表项：垂直 14px（`paddingListItem`），兼顾可点区域与信息量。
- 区块间距：模块间用 `sectionGap`（24px），内容块用 `contentBlockGap`（20px）。

### 间距节奏
- 基础单位 4px，阶梯 xs(4) / sm(8) / md(12) / lg(16) / xl(20) / xxl(24) / xxxl(32)。
- 同一模块内标题与内容间距 8–12px；卡片与卡片之间 12–24px 取一档并统一。

### 字号与比例
- 标题层级落差不超过 2 级；正文 bodyMedium 行高 1.48，bodySmall 1.42。
- Caption/Overline 略收紧行高（1.38/1.36）并加轻微 letterSpacing，提升商业感。

### 颜色对比度
- **Text Primary** #1A1A1A：白底对比度 >12:1。
- **Text Secondary** #525252：约 8:1，副标题层次清晰。
- **Text Tertiary** #737373：约 4.6:1，辅助信息仍符合 AA。
- 边框 **Border** #E5E5E5、**Divider** #EEEEEE，略柔和减少刺眼。

### 商业质感
- 卡片阴影 `cardElevated`：多层轻阴影，略加强第二层（alpha 0.07、blur 14），增强立体感。
- 主色/价格/CTA 与正文有明确字重与颜色区分；信任类标签（成团/退改/确认）使用统一语义色。
