# 首页中国卡通商业风重构 · 设计说明

## 第一阶段：视觉风格重定义

### 1️⃣ 当前页面问题分析（偏欧洲风的原因）

| 维度 | 当前表现 | 为何偏欧洲风 |
|------|----------|----------------|
| **整体背景** | 单一暖白/浅灰基底 + 一大块白色内容区 | 留白多、区块同色，偏北欧/极简的「一张白纸」 |
| **Header** | 真实摄影图 + 低饱和渐变，标题小、偏上 | 冷静、克制的视觉层级，缺少节日/亲子情绪 |
| **搜索栏** | 在 Header 下方、与内容区一起圆角卡片 | 更接近 Material 标准布局，非「顶部胶囊」 |
| **功能入口** | 3 排 4 列、图标偏线型、间距偏大 | 信息密度低、图标风格偏理性，非卡通饱满 |
| **推荐/亲子/周边** | 同一白底卡片内、仅靠标题分隔 | 模块感弱，没有「分区色块」的节日感 |
| **字体** | 多 400/500、少量 600/700 | 标题不够「加粗、活泼」，偏冷静 |
| **色彩** | 主绿 + 少量暖色点缀，区块无独立色 | 缺少高饱和分区色（红/绿/黄/蓝），节日感不足 |
| **插画** | Header 用旅行摄影图 | 非卡通插画，缺少亲子/春节的「手绘感」 |

结论：当前首页是「商业旅行 + 欧洲极简」的混合体，需要向「中国卡通商业风」做**分区色块、高饱和、插画头图、紧凑密度、加粗字体**的全面收敛。

---

### 2️⃣ 示例截图视觉语言总结

#### 颜色
- **Header**：高饱和红→橙渐变，带浅红/粉抽象纹样，节日主色。
- **功能区**：纯白底，与 Header 强对比。
- **推荐区**：整块**浅绿色**背景（#E8F5E8 系），模块独立色块。
- **亲子区**：整块**浅黄色**背景（#FFF9E6 系），活泼、亲子感。
- **周边活动**：**蓝色渐变**（上浅下略深），与红/绿/黄形成多色分区。
- **标签**：红色胶囊（热门）、绿色胶囊（有趣的一天）、灰色块（城市名）。
- **文字**：主标题黑且加粗，价格/强调用红，副信息灰但不弱化到「极简灰」。

#### 插画风格
- Header 右侧：**卡通人物**（圆润线条、背包/帽子/骑马），背后简化地图+温泉/灯笼/烟花等小元素。
- 整体：手绘感、圆角、不写实，偏春节/亲子主题。

#### Icon 风格
- 功能入口：**粗轮廓、带浅色背景块**（圆角方底），少量填充色（绿/橙），不是细线 icon。
- 统一为「卡通化」的符号，而非 Material 极简线型。

#### 字体感觉
- 主标题：**加粗、略大**，有手写/活泼感（如「新春首站之旅」白字红描边）。
- 区块标题：黑体加粗，清晰可读。
- 标签/副文：偏粗、行距紧凑，信息密度高。
- 避免细体、避免欧洲感无衬线「轻量」风格。

#### 模块分区方式
- **每个大模块独立背景色**：红橙 Header → 白 → 浅绿 → 浅黄 → 蓝渐变。
- 模块有**圆角容器**，不是全屏同色。
- 区块之间**颜色切换明显**，一眼能分出「推荐 / 亲子 / 周边」。

#### 标签样式
- **胶囊形**：热门（红）、有趣的一天（绿）、2~8人（红角标）、中信银行（品牌角标）。
- 城市标签：灰白底、小字，放在图左上或卡片上。
- 角标可贴在入口图标右上或卡片左上。

#### 背景使用方式
- Header：**插画 + 高饱和渐变**，不是纯色也不是低饱和图。
- 内容区：**按 Section 换色**，不用整页白或整页灰。
- 卡片：白/浅色卡片+阴影，落在彩色 Section 背景上，层次清晰。

#### 与当前方案的核心差异
- **分区**：从「一大块白」改为「多块高饱和/浅色背景」。
- **Header**：从「摄影+弱渐变」改为「卡通插画+强红橙渐变」，标题大、手写感，搜索顶置胶囊。
- **入口**：从「3 排、线型 icon」改为「2 排 5 列、卡通风 icon+浅底块、高密度」。
- **推荐/亲子/周边**：从「白底下列表」改为「绿/黄/蓝独立色块 + 贴纸感卡片/多列小卡/横滑大卡」。
- **字体与密度**：标题加粗、行距紧凑、信息密度提高，整体「中国本土商业 App」而非欧洲极简。

## 第二阶段：首页视觉架构重定义

### 一、顶部卡通插画 Header（约屏幕 30%）

- **背景**：卡通风插画（春节/亲子主题）+ 高饱和红→橙渐变叠加。
- **插画**：右侧人物（可骑马/背包等），左侧留出标题区；可选地图/灯笼/烟花等小元素。
- **标题**：左侧大字，手写感/活泼字体，白字可加红描边或阴影，如「新春首站之旅」类文案。
- **搜索栏**：
  - 位置：**屏幕最顶部**（SafeArea 下第一元素），不居中在 Header 中部。
  - 样式：**白色胶囊**，圆角 30+，带**定位 icon + 城市名（如安顺市）** + 搜索 icon + hint「和种草官一起环游...」。
- Header 高度：约 30% 屏高。

### 二、功能入口区域（仅两排）

- **布局**：两排 × 5 列（共 10 个入口）。
- **功能顺序**：社交旅行、亲子旅行、定制旅行、小包团、跟团游 / 周边活动、亲子活动、周边商城、游玩笔记、办卡有礼。
- **小包团**：右上角红色角标「2~8人」。
- **办卡有礼**：角标「中信银行」或类似。
- **Icon**：卡通风（粗轮廓/填充感），每个 icon 下有**浅色背景块**（圆角方）。
- **标签**：黑色偏重，行距紧凑，视觉密度高；不排 3 排、不留大量空白。
- **背景**：本区为**白色块**，与 Header 红橙形成对比。

### 三、推荐区（享梦游种草官）

- **背景**：**浅绿色**独立色块，模块圆角。
- **标题**：左侧小装饰 icon（如叶子）+「享梦游种草官」，右侧「更多>」。
- **内容**：**人物卡**样式，类似贴纸（圆角 12–16、阴影），**两卡并排**展示。
- **卡片**：头像+名字，可带定位等；整体像「推荐栏目」而非普通列表。

### 四、亲子活动区

- **背景**：**浅黄色**独立色块，圆角。
- **标题**：可带 emoji 或小图标，风格活泼。
- **内容**：**小图多列**（横滑或 2 列网格），每卡**城市标签**（如武汉市）在图上或卡上。
- 不做当前的大图横滑，改为更紧凑的「多列小卡」。

### 五、周边活动区

- **背景**：**蓝色渐变**整块（上浅下深），圆角。
- **标题行**：右侧**绿色胶囊**「有趣的一天」+「查看全部活动>」。
- **卡片**：横向滑动，每卡**左上角红色「热门」胶囊**（部分卡片），底部**时间+城市+星期**，高对比、不用灰弱化。
- 卡片图可保持 16:9，整体高对比、偏商业感。

### 六、模块分区

- 每个 Section 使用**独立背景色**：Header 红橙 → 功能白 → 推荐浅绿 → 亲子浅黄 → 周边蓝渐变。
- **禁止**整页单一白底；区块间边界清晰。

### 七、字体

- 标题加粗（600–700），标签略粗，避免细体与欧洲感。

### 八、图像资源

- **Header**：仅用**卡通插画图**（URL 或本地 asset），禁止真实摄影风。
- **活动/人物卡**：可用真实摄影图。

### 九、底部导航

- 选中态：**绿色**（与主色一致）。
- 图标风格统一，未选不用过灰，保持可读与商业感。

## 第三阶段：实现要点（代码层）

- **新 Home 结构**：Scaffold → Stack[Header 30% + 顶部搜索] + CustomScrollView[白区 Grid → 绿区推荐 → 黄区亲子 → 蓝区周边]。
- **颜色系统**：在 `AppColors` 中增加首页分区色（如 `homeSectionGreen`、`homeSectionYellow`、`homeSectionBlueStart/End`、Header 红橙沿用/强化）。
- **Section 组件**：可封装「带背景色+圆角+标题」的 Section 容器，内部再接 Grid/列表/横滑。
- **业务逻辑**：不改数据结构、不改接口、不删功能，仅替换视觉与布局。

以上为「中国卡通商业风」首页的完整视觉重定义与架构说明，供实现时严格对照。
