# 首页参考截图 · 视觉逆向分析

基于中国商业旅行 App 首页截图的视觉拆解，用于指导 Home 页面重构。

---

## 1️⃣ 整体视觉结构

| 维度 | 结论 |
|------|------|
| **顶部是否渐变** | 是。Hero 区域为明显暖色渐变背景。 |
| **Hero 区域高度比例** | 约 **30%～35%** 屏高，含主标题与背景插画。 |
| **内容区域是否圆角容器覆盖** | 是。Hero 下方为**大白色圆角容器**，顶部圆角约 **32px**，视觉上覆盖并延伸入 Hero 下方，形成分层。 |
| **层级** | **三层**：① 最底 = 顶部暖色渐变 + 主题插画；② 中间 = 浮在渐变上的搜索框（轻阴影）、Hero 标题；③ 最上 = 白色圆角内容容器，占主屏面积。 |

---

## 2️⃣ 色彩系统

| 维度 | 结论 |
|------|------|
| **主色调** | **暖红 + 橙**，Hero 区最明显。 |
| **渐变方向** | **自上而下**：上端较深暖红 → 下端较浅暖橙。 |
| **是否偏暖** | 整体**偏暖**，热情、活力感。 |
| **白色区域** | 内容区白底**非纯白**，略**暖白/米白**，与顶部暖色协调。 |

---

## 3️⃣ 信息密度

| 维度 | 结论 |
|------|------|
| **Icon 网格列数** | **4 列**。 |
| **间距** | Icon 网格水平/垂直约 **12～16px**；卡片之间紧凑但可区分。 |
| **圆角** | 搜索框 **20～24px**；主白容器顶部 **约 32px**；功能入口 icon 背景 **8～12px**；内容卡片 **约 16px**；「热门」标签为**胶囊圆角**（全圆角）。 |
| **卡片阴影** | **轻、柔**，有浮动感，不浓重。 |

---

## 4️⃣ 字体层级

| 角色 | 字号 | 说明 |
|------|------|------|
| **Hero 主标题** | 约 **36～40sp** | 艺术化/加粗，强视觉冲击。 |
| **一级区块标题**（如「享梦游种草官」「周边活动」） | **18～20sp** | 加粗，区块主题。 |
| **卡片内标题** | **15～16sp** | 加粗，清晰。 |
| **搜索占位 / 副标题** | **14sp** | 标准正文。 |
| **卡片描述** | **12～13sp** | 小字号，信息密。 |
| **Icon 下功能标签** | **12～13sp** | 最小档。 |
| **「热门」/ 日期地点** | **10～12sp** | 小字、白字或灰字。 |
| **价格** | — | 商业 App 中价格常**加粗**强调。 |

---

## 5️⃣ 与现有 Design Token 的映射

- **PrimaryGradient（暖）**：Hero 用暖红→橙，与现有绿色主色并存，仅 Hero 使用。
- **SurfaceWhite**：内容区用**暖白**（如 `#FFFBF7` / `#FFF9F5`），不纯白。
- **Spacing**：4 / 8 / 12 / 16 / 20 / 24 / 32 已覆盖。
- **Radius**：补充 16 / 20 / 24 / 32 语义（搜索 24、卡片 16、主容器顶 32）。
- **Shadow**：Light / Medium / Floating（Y 向 4～8）统一方向。

— 用于「商业化 Design Token」与 Home 重构的单一参考。
